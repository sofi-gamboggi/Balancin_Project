# Balancin_Project
Balancin es un programa pensado para ayudar a emprendedores/empresas a organizar sus estadísticas, facturacón y productos, todo en un mismo lugar. Se trata de un pseudo ERP que permite crear facturas simples, dar de alta o baja clientes y productos, y armar estadisticas segun la facturación registrada. Programado en lenguaje C
